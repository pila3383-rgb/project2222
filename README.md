# 🛡️ GhostTrace (v0.1-Demo)

**Автономный санитайзер документов и детектор цифровых следов.**

GhostTrace защищает корпоративную и личную приватность перед отправкой файлов контрагентам или публикацией в сети. Утилита работает **100% офлайн** и решает проблемы, недоступные обычным очистителям метаданных (ExifTool, инспектор Word).

📺 **[Смотреть видеодемонстрацию работы (YouTube)](https://youtu.be/AwvID5GSgBc?si=fxYYntZKdzRRQWuZ)**

---

## 🚀 Ключевые возможности

1. **Глубокая очистка контейнера (Binary Sanitizer):** Пересборка структуры документа (PDF) с полным удалением скрытых тегов, имен авторов, путей локальных серверов и истории изменений.
2. **Детектор стеганографии (Shannon Entropy):** Расчет энтропии Шеннона по байтам файла для выявления зашифрованных закладок и скрытых вставок.
3. **Стилометрический аудит (Anti-Stylometry):** Локальный анализ текста (длина предложений, лексическое разнообразие) для оценки риска деанонимизации автора нейросетями.

## 📦 Установка и запуск

### Вариант 1: Готовый исполняемый файл (Windows)
1. Скачайте `GhostTrace_v0.1.exe` из раздела [Releases](../../releases).
2. Запустите файл и перетащите нужный `.pdf` документ в окно консоли.
3. Очищенный файл сохранится рядом с суффиксом `_clean.pdf`.

### Вариант 2: Запуск из исходного кода
Требуется **Python 3.11+**.

```bash
# Клонирование репозитория
git clone https://github.com
cd GhostTrace

# Установка зависимостей
pip install pypdf

# Запуск
python main.py
```

## 🛠 Технологический стек

* **Язык:** Python 3.11
* **Парсинг и пересборка:** `pypdf` (в планах: `lxml` и `PyMuPDF` для расширенной работы с DOCX/PDF)
* **Сборка:** PyInstaller (единый портативный `.exe` без внешних зависимостей)

## ⚠️ Дисклеймер и безопасность

* Программа работает полностью локально — ваши документы никуда не отправляются.
* При первом запуске `.exe` система Windows SmartScreen может выдать предупреждение из-за отсутствия коммерческой цифровой подписи. Вы можете проверить исходный код или собрать бинарный файл самостоятельно через `pyinstaller --onefile main.py`.
